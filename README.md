# UI 实验室

一个用于收集交互与动效实验的轻量静态网站。

- 触感透视卡片：按住并移动时，卡片跟随指针产生 3D 倾斜和径向反射流光；松手后通过 Spring 阻尼自然回正。
- 流体胶囊形变：胶囊按钮与弹窗面板之间通过同一套高阻尼流体曲线完成尺寸、圆角和内容层级过渡。
- 共享元素无缝展开：Card 与详情视图共享容器和背景，连续完成空间缩放。
- 磁吸游标与滚动码表：游标直接跟随鼠标连续插值，靠近节点时轻微吸附，并用滚动数字同步当前数值。
- 阻尼弹性抽屉：支持橡皮筋阻力、速度预测和三档锚点吸附。
- 动态弥散光晕边框：旋转 Conic Gradient 描边与呼吸模糊背光。
- 物理弹簧交错流：列表元素通过 Stagger Delay 与微弹性依次上滑。
- 弹性微缩触觉反馈：按压缩放至 0.96，释放时产生轻微超调回弹。

八个实验入口以卡片堆呈现，展开时使用弹簧交错动画；选择不同实验会同步切换整个页面的环境光、边界与强调色。

## 本地预览

直接打开 `index.html`，或使用任意静态文件服务器启动仓库根目录。

## 添加新实验

页面壳层、实验导航和交互代码已分离。后续实验可以新增独立模块或页面，并在实验导航中注册入口。
